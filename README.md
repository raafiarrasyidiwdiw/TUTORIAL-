# Rawat HP Lebih Lama — GitHub Pages

Website statis bertema gelap untuk berbagi tutorial perawatan HP.

## Struktur
```text
├── index.html
├── README.md
└── files/
    └── battery-sound-notification.7z
```

## Cara upload ke GitHub

1. Buat repository baru di GitHub.
2. Upload `index.html`.
3. Upload folder `files` beserta `battery-sound-notification.7z`.
4. Buka **Settings → Pages**.
5. Pada **Build and deployment**, pilih **Deploy from a branch**.
6. Pilih branch `main` dan folder `/ (root)`.
7. Klik **Save**.
8. Tunggu GitHub Pages selesai melakukan deployment.

Setelah aktif, GitHub akan memberikan alamat website Pages untuk repository tersebut.

## Catatan
Website ini sengaja dibuat tanpa framework sehingga ringan dan mudah diedit langsung dari GitHub.
